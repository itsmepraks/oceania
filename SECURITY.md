# Security Policy

Oceania is a public component registry. Please report security issues privately
before opening a public issue.

## Reporting a Vulnerability

Email the maintainer at `53210833+itsmepraks@users.noreply.github.com` with:

- A short description of the issue
- Steps to reproduce it
- Affected component or registry URL
- Any relevant dependency versions

Please avoid posting exploit details publicly until there is a fix or a clear
mitigation.

## Supported Versions

The `main` branch is the supported development line. This project is pre-1.0,
so compatibility may change between releases.
